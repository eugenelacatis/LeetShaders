# Eval fixtures

Generated by `../gen/generate.ts` from `src/challenges/` and `../gen/specs.ts`. Edit the specs and regenerate instead of editing these files by hand.

```
fixtures/
  challenges/
    <slug>.glsl      reference shader (copied from src/challenges/)
    <slug>.json      challenge metadata, id = slug
  correct/<slug>-<label>.glsl
  almost-correct/<slug>-<label>.glsl
  wrong/<slug>-<label>.glsl
  adversarial/<slug>-<label>.glsl
  split.json         tuning / held-out fixture keys
```

A fixture's key is `<category>/<slug>-<label>`. The challenge is the longest slug that prefixes the file name.

Each harness run writes `<fixture>.png` (the user render at default uniforms) next to the fixture and `challenges/<slug>.png` for the reference. They are gitignored.

Methodology, expected outcomes, and band calibration are in `../CALIBRATION.md`.
